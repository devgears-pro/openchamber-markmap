# Markmap

## Links

- [Markmap](https://markmap.js.org/)
- [Source](https://github.com/markmap/markmap)

## Features

- Headings and lists become branches
- **Inline** ~~Markdown~~ _works_
- `code` and [links](https://openchamber.dev) work too
- Paragraphs become notes on a node

## Controls

- Scroll to zoom
- Drag to pan
- Click a fold dot to collapse a branch
- Use the file toolbar for the source view
